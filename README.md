# MLOps HW1: Real-Time Fraud Detection (Базовая версия)

Решение реализует потоковый скоринг фродовых транзакций на основе кодовой базы семинара. Система полностью удовлетворяет требованиям на оценку 6–7 баллов.

## 🏗 Архитектура
1. **Kafka**: Брокер сообщений (топики `transactions` и `scoring`).
2. **fraud_detector**: ML-сервис, который читает из `transactions`, выполняет препроцессинг, применяет модель и пишет результат в `scoring`.
3. **interface**: Streamlit UI для удобной загрузки CSV-файлов в Kafka.
